M&S Contabilidade Financeira - PWA

Alterações incluídas nesta versão:
- Ícone do aplicativo em formato de chapéu de formando com as letras M&S.
- Botão de instalação para Android, ocultado após instalação.
- Modo noturno com alternância por botão.
- Toast especial para nota maior que 80%: “se o Sales estivesse aqui, estaria orgulhoso te enchendo de beijos” + coração, desaparecendo após 5 segundos.
- Questões médias e difíceis divididas em blocos separados. O usuário faz 25 médias e 25 difíceis separadamente em cada aula, com resultado independente por bloco.

Como publicar no GitHub Pages:
1. Envie todos estes arquivos para a raiz do repositório: index.html, manifest.webmanifest, sw.js e a pasta icons.
2. Ative o GitHub Pages no repositório.
3. Abra a URL HTTPS gerada pelo GitHub Pages no Chrome do Android.
4. Toque no botão “Instalar”. Após instalado, o botão deixa de aparecer.

Observação: um PWA instalável precisa de manifest.webmanifest e sw.js separados, por isso o pacote contém esses arquivos além do index.html.
